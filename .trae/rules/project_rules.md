项目开发规则
1. 本项目使用原生 HTML、CSS 和 JavaScript 开发，不使用 React、Vue 等前端框架；
2. 不引入第三方 UI 组件库；
3. HTML、CSS 和 JavaScript 分别放在对应文件中；
4. 保持现有页面结构，不要随意修改与当前任务无关的功能；
5. 修改功能前先阅读现有代码，优先复用已有结构和逻辑；
6. 页面需要兼容桌面端和移动端；
7. 新增功能后必须在浏览器中进行验证；
8. 修改代码后不得破坏已有功能，特别是项目类别筛选功能；
9. 如果需求存在歧义，应先向开发者确认，不要自行猜测；
10. 每次修改尽量控制范围，避免一次修改大量无关代码。
