# 个人作品集网站

一个使用原生 HTML / CSS / JavaScript 编写的个人作品集单页网站，用于展示个人介绍、技能方向、项目作品与联系方式，并支持深浅色主题切换。

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（ES6+），不使用任何前端框架
- 不引入第三方 UI 组件库，所有样式与交互均自行实现
- CSS 变量（自定义属性）统一管理配色，Grid / Flex 实现布局
- `localStorage` 保存用户的主题选择
- 原生 SVG 图标与 Canvas/SVG 占位图

## 目录结构

```
lab04/
├── index.html        # 页面结构（侧栏 + 主内容区）
├── css/
│   └── style.css     # 全部样式，含浅色/深色主题变量
├── js/
│   ├── data.js       # 个人技能与项目数据（内容维护入口）
│   └── main.js       # 渲染、轮播、导航、主题切换等交互逻辑
└── 头像.jfif         # 侧栏头像
```

## 运行方式

方式一：直接用浏览器打开 `index.html`。

方式二（推荐）：在 `lab04` 目录下启动本地静态服务器，避免部分浏览器对本地文件读取的限制：

```bash
cd lab04
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 主要功能

1. **个人信息展示**：头像、姓名、专业方向、简介。
2. **技能标签联动**：点击侧栏技能标签，页面平滑滚动到「技能介绍」中对应条目并高亮。
3. **技能介绍**：按分组展示技能名称、熟练度标签、说明与五段式熟练度进度条。
4. **项目作品**：每个项目左右分栏展示，左侧为图片轮播（自动播放、左右切换、圆点导航），右侧为分类、时间、标题、简介与技术标签。
5. **导航高亮**：滚动页面时自动高亮当前所在板块的导航项，点击导航平滑滚动定位。
6. **深浅色主题切换**：侧栏导航上方提供切换按钮，可切换浅色/深色主题；页面背景、文字、边框等颜色同步变化，并通过 `localStorage` 记住上一次选择，刷新后仍生效。
7. **响应式布局**：桌面端为左右分栏，窄屏（≤900px）自动切换为上下布局。
8. **图片加载兜底**：图片加载失败时自动替换为内嵌渐变占位图。

## 内容维护

页面中的技能与项目数据集中在 `js/data.js`：

- `profileData.skills`：技能分组、技能名称、熟练度（1–5）与说明；
- `projectsData`：项目标题、分类、时间、技术栈、简介与图片地址，新增项目只需在数组中追加一条记录。
